Battery Digital Twin: infrastructure components, how they connect, their key settings, and the five repositories.
Click a component for its settings and connections. Click empty space to reset.

Five repositories under github.com/rdcsung. Arrows on the map's “Repos & delivery” lens show the same relations.

Hand-made Secrets live in Vault (KV v2 at secret/) and are synced into each namespace by External Secrets (creationPolicy: Orphan, hourly). A namespace's vault-eso service account can read only secret/k8s/<its namespace>/*. Values are never shown here.

Not in Vault on purpose: cert-manager TLS Secrets, Argo CD's own Secrets (incl. gitops-repo-creds), chart-generated Secrets (e.g. airflow-broker-url), Vault's unseal key and root token, the MinIO root login (Ansible vault in bdt-infra), and Airflow's minio_s3 connection (Airflow DB; backlog PL-3).

Upkeep rules

  1. Any change that adds, removes or reconfigures a component, host, URL, port, Secret, Vault path, repo relation or pipeline step updates MODEL in this file in the same change (rule in AGENTS.md).
  2. Bump MODEL.updated and add a line to MODEL.changelog.
  3. Facts only, checked against the repos or the cluster; never secret values.
  4. New component: add a node (pick a lane), its kv, its src (where it's defined), and its edges with the right type.
